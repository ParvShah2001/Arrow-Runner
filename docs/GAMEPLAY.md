# Arrow Runner — Gameplay Guide & Reference

This guide details the controls, entity mechanics, scoring mechanics, speed progression tiers, and customizable skin shop items in **Arrow Runner**.

---

## 🕹️ Controls

| Platform | Action | Control |
| :--- | :--- | :--- |
| **Mobile / Touch Screen** | Move Left | Tap Left Half of Screen |
| **Mobile / Touch Screen** | Move Right | Tap Right Half of Screen |
| **Keyboard** | Move Left | `← Arrow Left` or `A` |
| **Keyboard** | Move Right | `→ Arrow Right` or `D` |
| **Keyboard** | Pause / Unpause | `P` or `Esc` |

| Entity | Icon | Type | Effect / Points |

| **Score Orb** | 🔮 | Point Collectible | `+10 Points × Combo Multiplier`, increases combo count. |

| **Hazard Spikes** | 💣 | Danger Obstacle | Deducts 1 Life heart, resets combo multiplier. Game over at 0 lives. |

## ⚡ Speed Progression Scaling

Arrow Runner features progressive speed scaling:

1. **Initial Speed**: Base scroll speed of `7.5`.
2. **Tiered Scaling (0 – 10,000 Points)**: Scroll speed increases by `+1.25` for every **2,000 points** scored. Floating notification `SPEED UP! ⚡` notifies the player.
3. **Hyperspeed Tier (10,000+ Points)**: Scroll speed jumps drastically to `13.5` and scales up to **`22.0`** max speed with spawn intervals dropping down to 16ms! Floating notification `🔥 DRASTIC HYPERSPEED! 🔥` warns the player.

## 🎨 Skin Shop System

Players earn coins in runs and spend them in the **Skins Shop** (`#skins-screen`) across 4 categories:

1. **🚀 Arrow Skins**: Customize your vessel (Classic Stealth, Gold Vector, Cyber Razor, Quantum Pulsar, Toxic Viper, Cryo Hawk, Solar Valkyrie, Void Shadow, Matrix Drone, Titan Omega).
2. **💣 Hazard Skins**: Customize danger obstacles (Crimson Spike, Bio Core, Plasma Trap, Nuclear Core, Cryo Cluster, Magma Saw, Void Hole, Glitch Box, Laser Pyramid, Skull Mine).
3. **🔮 Points Skins**: Customize collectible orbs (Emerald Pearl, Cyan Spark, Golden Star, Magenta Gem, Violet Soul, Fire Teardrop, Snow Crystal, Matrix Cube, Hyper Diamond, Cosmic Core).
4. **🪙 Coin Skins**: Customize currency tokens (Gold Dollar Coin, Cyber Credit, Ruby Drop, Emerald Prism, Sapphire Star, Amethyst Shard, Casino Chip, Crypto Coin, Solar Medallion, Quantum Relic).
